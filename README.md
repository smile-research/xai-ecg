# Robustness of XAI Explanations for ECG Classification Under Image Augmentation

## Abstract

This repository provides the full reproducible pipeline for evaluating the robustness of Explainable AI (XAI) methods applied to cardiovascular disease classification from 12-lead electrocardiogram (ECG) signals. The study investigates how image-domain augmentations — simulating real-world degradation of paper ECG recordings (wrinkles, handwritten annotations, dewarping artifacts) — affect the stability of post-hoc explanations generated by gradient-based and perturbation-based XAI techniques.

The pipeline encompasses six stages: (1) waveform-to-image rendering under controlled augmentation scenarios, (2) optional custom augmentation composition, (3) explanation generation via five XAI methods across an ensemble of independently trained classifiers, and (4) quantitative robustness assessment through radiomics feature extraction and inter-method agreement (IoU) analysis.

## Methodology

### Classification Models

Three independently trained deep learning classifiers perform multi-label cardiovascular diagnosis using binary cross-entropy loss:

| Architecture | Description |
|---|---|
| ResNet1D | Residual network adapted for 1D ECG signals (Wang et al.) |
| Inception1D | Multi-scale 1D inception modules for temporal pattern capture |
| ConvTransformer | Hybrid convolutional–transformer architecture for long-range dependencies |

Models are trained with 10-fold cross-validation on the PTB-XL dataset. Fold 10 is held out exclusively for evaluation across all experiments.

### XAI Methods

Five post-hoc explanation methods are applied via [Captum](https://captum.ai/):

| Method | Type | Reference |
|---|---|---|
| Saliency | Gradient-based | Simonyan et al., 2014 |
| Integrated Gradients | Path-integrated gradient | Sundararajan et al., 2017 |
| GradientShap | Stochastic gradient × input | Erion et al., 2021 |
| Occlusion | Perturbation-based | Zeiler & Fergus, 2014 |
| LIME | Local surrogate model | Ribeiro et al., 2016 |

Explanations are normalized using **second-moment normalization** before ensemble aggregation (`compact_xai/EnsembleXAI/`).

### Augmentation Scenarios

Each scenario simulates a distinct real-world condition of paper ECG digitization:

| Scenario | Description | Rationale |
|---|---|---|
| `clear` | Clean rendering, no artifacts | Baseline reference |
| `no_header` | Header metadata removed | Isolates waveform signal |
| `text` | Synthetic handwritten text overlay | Simulates clinical annotations |
| `wrinkles` | Paper wrinkles and creases via texture synthesis | Simulates physical degradation |
| `all` | Combined grid, padding, rotation, color randomization | Full digitization variability |
| `all_stacked` | Union of all augmentations (all + text + wrinkles) | Worst-case degradation |
| `dewarped` | Wrinkled images processed with Fourier-based correction | Tests artifact removal efficacy |

### Robustness Quantification

Explanation maps are treated as 2D grayscale images and analyzed via [PyRadiomics](https://pyradiomics.readthedocs.io/) feature extraction:

- **Feature classes:** First-order statistics, GLCM, GLDM, GLSZM, GLRLM, NGTDM
- **Image filters:** Original, Wavelet, LBP2D, Gradient
- **Agreement metric:** Intersection-over-Union (IoU) computed pairwise between XAI methods across augmentation conditions

## Data

**[PTB-XL](https://physionet.org/content/ptb-xl/1.0.3/)** — 21,799 clinical 12-lead ECG recordings (10 s, 500 Hz) from 18,869 patients, annotated with up to 71 diagnostic statements conforming to the SCP-ECG standard. The dataset provides pre-defined 10-fold stratified splits; this work uses fold 10 as the held-out test set (N ~ 2,200 recordings).

| Variable | PTB-XL | Test fold 10 |
|---|---|---|
| Total recordings | 21,799 | 100 |
| Female / Male | 11,354 / 10,445 | 55 / 45 |
| Age (mean ± std) | 59.5 ± 16.8 | 55.0 ± 17.9 |
| Age (range) | 2–89 | 17–86 |
| Weight, kg (mean ± std) | 71.0 ± 15.9 | 73.9 ± 15.1 |
| Height, cm (mean ± std) | 166.7 ± 10.9 | 168.3 ± 11.5 |
| Target (positive / negative) | 9,514 / 12,285 | 51 / 49 |

## Reproduction

### 1. Environment Setup

```bash
# Configure W&B credentials for model artifact retrieval
cp explanation_generation/.env.example explanation_generation/.env
# → set WANDB_API_KEY in the .env file

# (Optional) Install uv if not present
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 2. Model Configuration

Update W&B model artifact references in:
- `explanation_generation/run_all.sh` — `MODELS` array
- `explanation_generation/configs/xai_local.json` — `model` field

These should point to your trained model artifacts stored in W&B.

### 3. Full Pipeline Execution

```bash
# Run all six stages end-to-end
bash pipeline.sh

# Preview commands without execution
bash pipeline.sh --dry-run

# Resume from a specific stage
bash pipeline.sh --from-stage 4

# Run a single stage in isolation
bash pipeline.sh --only-stage 2
```

### 4. Custom Augmentation Experiments

Stage 3 supports user-defined augmentation chains via JSON configuration:

```bash
bash pipeline.sh --only-stage 3 \
    --stage3-config single_augmentation/configs/example_config.json \
    --stage3-input  augmentation_generation/output/clear \
    --stage3-output single_augmentation/output
```

See `single_augmentation/configs/` for configuration examples covering individual and composed augmentations.

## Module Reference

### `augmentation_generation/`

Renders PTB-XL WFDB waveforms into 12-lead ECG images using Matplotlib, then applies scenario-specific augmentations (wrinkles via texture synthesis, handwritten text via a pre-trained generative model, geometric transforms via `imgaug`). Fourier-based dewarping removes wrinkle artifacts for the `dewarped` scenario.

```bash
cd augmentation_generation
uv run python prepare_fold10_inputs.py      # Extract fold-10 WFDB records
bash run_all_scenarios.sh                    # Generate all 7 scenarios
```

**Outputs:** `output/<scenario>/` — PNG images organized by augmentation scenario.

### `single_augmentation/`

Applies configurable, sequential augmentation steps to existing ECG images. Each step (wrinkles, geometric augmentation, handwritten text) is independently parameterized via JSON configuration.

```bash
cd single_augmentation
uv run python apply_augmentations.py \
    --input_dir <images> --output_dir <output> \
    --config configs/example_config.json
```

### `explanation_generation/`

Retrieves pre-trained classifiers from W&B artifacts, loads ECG image data, and generates per-sample XAI explanation maps using Captum. Explanations are saved as NumPy arrays (`.npz`). Ensemble aggregation normalizes and combines explanations across methods.

```bash
cd explanation_generation
uv run python generate_explanations.py \
    --config_file configs/xai_local.json \
    --output_dir ./outputs \
    --from_index 0 --to_index 100

# Full combinatorial run (3 models × 7 augmentations):
bash run_all.sh
```

**Outputs:** `outputs/` — NPZ files containing explanation arrays per sample, method, and model.

### `radiomics/`

Converts explanation maps to SimpleITK images and extracts radiomics features (93 features across 6 texture classes, 4 image filter types). Computes pairwise IoU between explanation methods to quantify inter-method agreement under augmentation.

```bash
cd radiomics
uv run python generate_paths.py                          # Build path manifest
uv run python main.py -f 0 -t 200 -p batch1              # Extract features (batch)
uv run python calculate_stats.py \
    --npz_dir statystyki/explanations2 \
    --csv_dir output --output_dir results                 # Aggregate statistics
```

**Outputs:** Per-sample radiomics CSVs, aggregated feature statistics, IoU matrices.
